# 焱七 IP 人物定义

## 唯一视觉基准

`../assets/yanqi-ip-master.jpg` 是焱七身份的唯一视觉基准。它定义脸型、发型、发色、眼睛、肤色、服装、身材和常用表情。

基准图是角色设定页，不是正文配图模板。生成新图时只继承人物身份，不复制五宫格布局、同页多表情或站姿排列。

## 固定人物基因

以下特征不得随主题改变：

1. 年轻成年女性，气质明亮、亲和、有行动力。
2. 鲜亮莓粉色头发，颜色明确偏粉，不偏正红、紫色或橙色。
3. 头发浓密蓬松、自然卷曲、长度及腰，卷发体积是主要识别点。
4. 清澈明亮的蓝色大眼睛，细致睫毛，柔和鹅蛋脸。
5. 白皙象牙肤色，鼻尖和双颊有自然淡红晕，不得晒黑或变成深肤色。
6. 固定穿森林绿细肩带 A 字裙，裙摆在膝盖上方，设计简洁得体。
7. 纤细修长的成年人体型，肩颈舒展、腰线自然、腿部长而匀称。

## 身材与全身比例

- 不是 Q 版，不使用大头短身比例。
- 头部大小接近柔和动画写实比例，不得为追求可爱而继续放大。
- 全身画面必须让膝盖、裙摆、脚踝和脚部位置合理，腿长清晰可见。
- 裙摆位于膝盖上方，裙摆以下的腿部长度应明显大于小腿被压缩后的短比例。
- 基准设定页中的全身形象赤脚；具体场景确有需要时可以增加简洁鞋履，但不得改变腿部比例。

## 面部与表情

稳定表情范围来自基准图：

- 平静微笑：说明、倾听、陪伴
- 开心大笑：完成、发现、庆祝
- 侧目浅笑：判断、机灵、轻松吐槽
- 不满拒绝：排除、避坑、否定错误方案
- 睁眼惊喜：新发现、灵感、意外收获

可以在此范围内变化视线、嘴型、眉形和手势，但不能换脸、改变眼睛颜色或变成幼童面容。

## 人物在画面中的职责

焱七必须亲自完成核心动作，例如整理、筛选、连接、递交、搭建、观察、比较、记录或修复。优先选择双手能参与的动作，让动作本身解释文章观点。

不允许只站在标题旁、指向现成图表、摆拍或作为无关装饰。

## 可变范围

允许随内容变化：姿势、视角、表情、手中物品、少量配饰、场景道具和简单鞋履。森林绿吊带裙保持固定；如环境需要外搭，必须让吊带裙和人物核心识别点仍然清楚。

## 禁止漂移

- 头发变成红色、紫色、橙色、短发、直发或低发量
- 眼睛变色，肤色明显变深，脸型或年龄漂移
- 更换森林绿吊带裙，或把裙子改成礼服、制服、裤装
- 生成 Q 版、大头娃娃、幼童体型、小短腿或粗矮比例
- 用五个不同人物代替同一焱七的五种表情
