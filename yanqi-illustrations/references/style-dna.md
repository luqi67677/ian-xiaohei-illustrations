# 焱七配图画风 DNA

## 一句话定义

纯白画布上的细腻柔和数字插画：鲜亮莓粉长卷发与森林绿裙形成高识别度主体，轮廓干净，人物和物体表面有轻微细颗粒质感，整体明亮、清爽、有呼吸感。

## 必须满足

- 16:9 横向正文配图。
- 背景为真正的纯白 `#FFFFFF`，没有米黄、奶油色、暖白渐变或旧纸底色。
- 背景无纹理；轻微细颗粒仅用于人物、头发、服装和物体表面。
- 轮廓柔和但清楚，发丝和卷发层次细腻，皮肤通透白皙。
- 只表达一个核心概念，主体集中，四周保留充足留白。
- 道具少而明确，中文标签通常控制在 3—6 个短词。
- 焱七的动作与道具共同承担解释任务。

## 核心颜色

- 背景白：`#FFFFFF`
- 鲜亮莓粉发色：高饱和粉红偏莓色，不偏红紫
- 森林绿裙：深而稳定的自然绿色
- 眼睛蓝：清澈明亮的湖蓝至天蓝
- 肤色：白皙象牙色，少量桃粉红晕

辅助色只用于信息层级，可使用低饱和浅蓝、浅绿、桃粉和少量暖黄；不得抢过人物发色。

## 线条与质感

- 数字绘制的柔和细线和精细边缘，不使用粗黑漫画描边。
- 卷发应有层叠发束、体积和自然高光，避免塑料丝或整块色团。
- 服装有轻微柔软织物质感，道具适度简化，不追求照片级材质。
- 光线均匀、明亮、柔和；不使用强烈电影光、厚重阴影或高反差背景。

这里的质感定义为“细腻柔和、带轻微细颗粒的数字插画”，不是彩铅、水彩、蜡笔或纸本插画。

## 构图气质

画面像一段文章中的视觉停顿：第一眼看见焱七在做什么，第二眼理解元素之间的关系，最后读到少量必要标签。不要把所有内容塞进一张图。

## 绝对禁用

- 米黄、奶油、复古纸张、宣纸、纸纤维、颗粒背景、渐变、散景
- 彩铅、水彩、蜡笔、油画、厚涂、照片、3D 渲染、塑料玩具质感
- Q 版、大头短身、小短腿、幼儿化比例
- PPT 模板、企业信息图、复杂 UI 面板、密集图标墙
- 霓虹赛博朋克、暗黑电影感、强光晕和过度高光
- 大段正文、难辨小字、无意义英文装饰
