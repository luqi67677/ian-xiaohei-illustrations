# 交付前质检清单

任一硬性项失败，都不得直接交付，应使用定点修复提示词重绘。

## 1. 人物身份硬性项

- [ ] 与 `../assets/yanqi-ip-master.jpg` 是同一个焱七，不换脸、不改变年龄。
- [ ] 头发是鲜亮莓粉色、浓密蓬松、及腰长卷发，不偏红、紫或橙。
- [ ] 眼睛清澈明亮且为蓝色。
- [ ] 肤色白皙象牙色，仅有自然淡红晕，没有明显变黑。
- [ ] 固定穿森林绿细肩带 A 字裙，裙摆位于膝盖上方。
- [ ] 身材为纤细修长的年轻成年比例，不是 Q 版、大头娃娃或幼童。
- [ ] 若出现全身，腿部长而匀称，膝盖、脚踝和脚部位置自然，没有小短腿。

## 2. 画风与背景硬性项

- [ ] 画幅为 16:9 横图，除非用户明确指定其他比例。
- [ ] 背景为均匀纯白 `#FFFFFF`。
- [ ] 没有米黄、奶油色、暖白渐变、纸张纹理、背景颗粒或散景。
- [ ] 风格是细腻柔和数字插画；轻微细颗粒只在人物和物体表面。
- [ ] 没有彩铅、水彩、蜡笔、照片、3D 或塑料玩具质感。

## 3. 内容表达

- [ ] 第一眼能看出焱七正在做什么。
- [ ] 动作直接解释唯一核心概念，人物不是旁观装饰。
- [ ] 道具数量克制，每个元素都有明确作用。
- [ ] 阅读顺序由视线、手势、箭头或空间关系清楚引导。
- [ ] 没有照搬五宫格角色设定页。

## 4. 文字与版面

- [ ] 中文标签准确、清楚、简短，通常不超过 3—6 个。
- [ ] 没有乱码、错字、无意义英文或重复标签。
- [ ] 主体没有被裁切，道具与标签不互相遮挡。
- [ ] 四周有足够留白，画面没有拥挤、溢出或失衡。
- [ ] 不是 PPT 模板、复杂 UI 或密集图标墙。

## 5. 定点返修顺序

1. 先修人物身份和身体比例。
2. 再修纯白背景与画风。
3. 再修核心动作和构图关系。
4. 最后修中文字和局部细节。

每次只修一个问题，明确要求其他内容保持不变，避免整图重绘导致人物继续漂移。
