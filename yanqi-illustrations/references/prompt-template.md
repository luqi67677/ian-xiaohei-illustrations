# 提示词模板

生成时必须同时传入 `../assets/yanqi-ip-master.jpg` 作为人物参考图。模板中的内容字段按任务替换，不要删除人物身份、纯白背景和比例约束。

## 完整生成模板

```text
生成一张独立的 16:9 横向中文文章正文配图。

严格使用随附的焱七角色设定图锁定人物身份，但不要复制角色设定图的五宫格排版，也不要生成表情设定页。

【固定人物】
焱七，年轻成年女性；鲜亮莓粉色、浓密蓬松、及腰的自然长卷发；清澈明亮的蓝色大眼睛；白皙象牙肤色，双颊有自然淡红晕；固定穿森林绿细肩带 A 字裙，裙摆在膝盖上方；身材纤细修长，肩颈舒展，腿部长而匀称。保持与参考图相同的脸、发型、发色、眼睛、肤色、服装和气质。不是 Q 版，不是幼童，不要大头短身或小短腿。

【画风】
细腻柔和的数字插画，轮廓干净，卷发层次丰富，人物和物体表面只有轻微细颗粒质感。背景必须是纯白 #FFFFFF，没有米黄、奶油色、暖白渐变、纸张纹理、颗粒底纹或散景。不是彩铅、水彩、蜡笔、油画、照片或 3D。

【主题】
{要表达的唯一核心判断}

【结构】
{流程 / 分类 / 前后对比 / 系统局部 / 层级 / 路径 / 隐喻 / 轻叙事}

【核心动作】
焱七亲自{整理 / 筛选 / 连接 / 递交 / 搭建 / 修复 / 记录 / 观察 / 比较}，动作直接解释主题，不能只站在旁边指向现成图表。

【构图】
{主体位置、人物取景、道具位置、阅读方向、留白位置}

【必要元素】
{只列与主题直接相关的 2—5 个物件}

【中文标签】
{3—6 个短词；若不需要则明确写“无文字”}

【约束】
画面只表达一个核心概念；默认只出现一个焱七；信息层级清楚；道具简洁；留白充足；不做 PPT 模板，不堆叠图标，不加入无意义装饰。若使用全身构图，必须完整保留膝盖、脚踝和脚部位置，并保持参考图中的修长长腿比例。
```

## 定点修复模板

### 人物身份漂移

```text
保持现有场景、构图、动作、道具和文字完全不变，仅依据焱七基准图重绘人物：同一张柔和鹅蛋脸、鲜亮莓粉及腰蓬松长卷发、清澈蓝眼、白皙象牙肤色、森林绿细肩带 A 字裙。不要改变年龄、发色、眼睛颜色、服装或气质。
```

### 长腿比例修复

```text
保持人物身份、脸、发型、服装、姿势和画面构图不变，只修复全身比例：年轻成年女性的纤细修长体型，裙摆在膝盖上方，腿部长而匀称，膝盖、脚踝和脚部位置自然。不要放大头部，不要压缩大腿或小腿，不要 Q 版，不要小短腿。
```

### 背景修复

```text
保持人物和所有必要元素不变，只把整个背景改为均匀纯白 #FFFFFF，删除米黄、奶油色、暖白渐变、纸张纹理、颗粒底纹、阴影雾化和散景。细颗粒质感只保留在人物与物体表面。
```

### 文字修复

```text
保持画面其他部分不变，只修复中文标签。准确写为：{标签列表}。使用简洁清晰的中文字体，不增加任何其他文字。
```

### 动作修复

```text
保持人物身份、画风和信息结构不变，让焱七亲自完成“{核心动作}”。双手、视线和身体朝向都服务于该动作，删除只站立或只指向文字的无效姿势。
```
