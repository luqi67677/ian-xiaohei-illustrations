# 焱七 IP 正文配图

生成一张独立的 16:9 中文正文配图。焱七必须参与表达核心概念，而不是站在旁边充当装饰。

## 唯一人物基准

人物身份以 `assets/yanqi-ip-master.jpg` 为唯一视觉基准。生成时将它作为角色参考图传入；它只用于锁定人物身份，不得照搬五宫格排版。

如文字规则与基准图冲突，以基准图中的脸、发型、发色、眼睛、肤色、服装和身材比例为准。

## 生成前读取

按任务需要读取：

- `references/yanqi-ip.md`：人物固定基因与可变范围
- `references/style-dna.md`：画风、颜色、背景与禁用项
- `references/composition-patterns.md`：构图模式和人物动作
- `references/prompt-template.md`：完整提示词模板与修复提示词
- `references/qa-checklist.md`：交付前检查

## 工作流程

1. 从正文中提取一个核心判断、一个关系结构和一个最适合焱七完成的动作。
2. 选择一种构图模式，先确定主体、道具、箭头和少量中文标签的位置。
3. 使用图像生成工具，将 `assets/yanqi-ip-master.jpg` 作为角色参考图，并按 `references/prompt-template.md` 组织提示词。
4. 每张图默认只出现一个焱七。若表达前后对比或多状态，才允许同一人物重复出现。
5. 背景必须是纯白色。不得加入米黄、奶油色、纸张纹理、渐变或散景。
6. 全身构图必须保留修长成年比例、膝上裙摆和明显长腿；不得放大头部、缩短腿部或生成 Q 版身体。
7. 用 `references/qa-checklist.md` 检查人物一致性、核心动作、文字可读性和构图留白，不合格则定点重绘。

## 输出要求

- 默认画幅：16:9 横图
- 默认背景：纯白 `#FFFFFF`
- 默认语言：简体中文，标签短而少
- 默认人物：一个焱七，主动参与核心动作
- 默认风格：细腻柔和的数字插画，轻微细颗粒仅存在于人物和物体表面
- 输出文件：保存到用户指定路径；未指定时使用清晰的英文短文件名

不要把画风描述为彩铅、水彩、纸本插画或 Q 版。
